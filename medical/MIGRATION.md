# 이전 기록 (2026-10-11)

Drive 시트 `휴휴휴 의료정보_자료목록과 운영흐름`(MED-0001~0028, 28건)과 건별 txt/PDF를 이 저장소로 옮기고 체계를 재정비했다.
Drive의 기존 파일은 삭제·이름변경하지 않았고 각 자료의 `drive_file`로 연결했다.

## 기존 방식에서 확인한 문제와 조치

| # | 문제 | 조치 |
|---|---|---|
| 1 | 날짜 칸에 "미확인 / 미표기 / 본문 미표기 / 발행일 미표기 / 2026(연도만 표기)"가 섞여 있어 기계적 점검이 불가능 | `YYYY[-MM[-DD]]` 또는 `unknown` 으로 통일, 검증기가 위반 시 오류 |
| 2 | '원문 수정일' 칸에 시행일·첨부파일명 날짜가 들어감 (MED-0014: 첨부명 2026-04-02, MED-0016: 시행 2026-05-01, MED-0017: 시행 2025-09-19) | `effective`(시행일) 칸을 분리하고 `revised`는 `unknown`으로 정정 |
| 3 | 파일명 규칙이 "다음 새 자료부터 적용"이라 MED-0001만 `001_...` 형식, 규칙 문서와 실제가 불일치 | 저장소 파일은 전부 `MED-NNNN_기관_주제.md`로 통일, 검증기가 접두어 검사. Drive 원본 파일명은 건드리지 않음 |
| 4 | 급여 고시와 2018~2020년 미국 일반 안내가 같은 '검증 완료'로 취급 | 근거 등급 `tier` A/B/C와 `jurisdiction` 추가. 해외·구자료(MED-0007·0019·0020·0023·0025)는 `needs_recheck`, 국내 제도 근거로 사용 금지를 명시 |
| 5 | 재확인 시점이 대부분 "대본 반영 직전"이라 점검 대상이 되지 않음 | `recheck_by` 날짜 필수 (급여·제도 3개월, 의학 6개월, 보완 필요 1~2개월). 지나면 경고 + STATUS 표시 |
| 6 | 가장 중요한 원문(MED-0013 학회 지침 94쪽)이 '재열람 완료'로만 표시되고 내용 요약이 없음 | `partial`로 표시, 요약 작업을 BL-03로 등록 |
| 7 | MED-0018이 2차 출처(국가암정보센터)인데 1차 법령 출처 확인이 빠져 있음 | `needs_recheck` + BL-05 |
| 8 | 심평원 제2026-210호가 시트에 '미부여(보류)'로만 남아 번호도 자료도 없음 | 게시문 본문을 직접 확인해 MED-0029로 등록(신장암 항목 없음 확인). 첨부 전문은 BL-01 |
| 9 | 시트 '운영 흐름' 탭의 폴더 상태가 실제와 다름 ('치료'·'치료비_국가제도' 폴더 "자료 수집 전", 현재 범위에 "학회 지침 보완 필요"인데 MED-0013 이미 수집) | 시트 대신 `STATUS.md`를 코드로 자동 생성 (손으로 갱신하는 현황표 폐지) |
| 10 | 같은 첨부 다운로드 실패가 여러 회차에 반복 기록됨 (심평원 2026-210·2026-10-01 책자) | 1회 실패 시 중단 → `partial` + BACKLOG 규칙화 |
| 11 | 검토자 칸이 "ChatGPT"/"자동수집·재검증" 등으로 제각각, 의료인 검토 여부가 일부 파일에만 기재 | `reviewer`를 전 자료에 명시(의료인 검토 미실시) |
| 12 | 중복 판별이 사람의 눈에 의존 (MED-0011·0012는 메뉴 경로 차이를 별도 설명) | 검증기가 URL의 `cancer_seq/menu_seq/brdBltNo/SEQ/mid`로 중복 경고 |

- MED-0013 PDF 본문(66MB → Drive 링크로 참조)
- 시트의 '실행기록' 로그 (이전 사실은 git 이력으로 대체)

## 이전 시 원본과 달라진 점 (내용 정정 없음, 표현만 정리)
- 본문은 원 txt를 4섹션(핵심 근거 / 적용 조건·한계 / 미검증·사용 금지 / 영상 활용 메모)으로 재배치하고 일부 문장을 압축했다. 수치·조건은 바꾸지 않았다.
- 시트에만 있던 값(MED-0013 장 구성, 활용 영상·장면 등)은 시트 기준으로 옮겼다.
- 원 txt가 없는 MED-0013 본문은 시트 기재 범위만 옮겼다.
