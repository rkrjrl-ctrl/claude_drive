# 진단비·수술비의 KCD 코드 분쟁 가이드

- 기준일: 2026-10-18. 근거는 `status: verified` 기록이다(tier C 기록은 쓰지 않았다).
- 표기: [대법원]은 판결, [분조위]는 금융분쟁조정위원회 조정결정, [금감원 사례]는 금감원 민원·분쟁 처리 사례다. 연도는 결정 연도다.
- 옛 분조위 결정 기록에는 "이후 판례·약관 개정으로 결론이 달라질 수 있다"는 주의가 있다(MED-1695, MED-1824).
- 암의 경계성 종양·KCD 차수 쟁점은 [암진단_확정과_시점_가이드.md](암진단_확정과_시점_가이드.md) 4·5절이 더 자세하다(MED-1611). 이 문서는 KCD 개정 내용과 코드 해석 전반을 다룬다(MED-1606).

## 1. 먼저 알아 둘 것 — KCD는 통계 분류다

- KCD(한국표준질병·사인분류)는 통계 작성용 표준분류다(MED-1606).
  - 건강보험 청구 상병코드는 심평원 상병마스터 반영을 따른다(MED-1606).
- '9차 시행 = 모든 보험금 판단이 9차 기준'이 아니다. 민영보험 약관이 어느 차수 KCD를 인용하는지는 상품·가입 시기마다 다르다(MED-1606).
- 질병코딩지침서는 통계 코딩 지침이다. 보험금 지급 기준이나 약관 해석을 정하지 않는다(MED-1686, MED-1790).
- 연계표는 통계 시계열용이다. 개별 진단의 코드 결정은 분류표·지침서를 따른다(MED-1682).

## 2. 제9차 KCD(2026-01-01 시행)에서 바뀐 것

- **고시**: 통계청 고시 제2025-299호(2025-07-01 전부개정)이고 2026-01-01 시행이다. 코드 신설 67개, 삭제 91개다(MED-1606).
- **ICD-10 체계는 유지**된다(MED-1607).
  - 소분류는 2,085개에서 2,084개로, 세분류는 12,503개에서 12,506개로 바뀌었다(MED-1607).
- **주요 예**(MED-1607)
  - F32.2 치료저항성 우울증 세분
  - J82.1 호산구성 천식 신설
  - K29.60 위의 장상피화생
  - I50.1 좌심실부전 박출률별 세분
- **신생물**
  - 해부학적 부위 코드 신설은 D37.6(간·담낭·담관)과 D37.7(기타 소화기관) 세분뿐이다(MED-1683, MED-1682).
  - 형태분류(M코드)는 ICD-O-3.2 기준으로 125개를 정비했다(MED-1608).
  - 제자리·경계성 범주(D00-D09·D37-D48) 변경은 보도자료에 없다(MED-1608).
- **표제어만 바뀐 예**: 클라츠킨 종양이 '간문부 담관암종'으로 이름만 바뀌었다. 분류(C24.0)는 그대로다(MED-1608).
- **장기별로 갈린 예**: 고형 가유두모양 종양은 '난소의' 것이 D39.1-, '췌장의' 고형 가유두모양 신생물이 M8452/3(C25.-)으로 나뉘었다(MED-1683).
- **순환계**(MED-1684)
  - 협심증 I20.8에서 I20.81 안정협심증이 분리됐다.
  - I50.1이 세분되고 I50.04·I50.05가 삭제됐다.
  - 뇌혈관(I60-I69)은 한글 수정 1건뿐이고 코드 신설·삭제가 없다.
- **뇌졸중·급성심근경색 진단비의 대상 코드(I60-I63, I21 등)는 9차에서 번호가 바뀌지 않았다.** 다만 약관이 인용하는 차수와 범위는 계약마다 다르다(MED-1684).
- **정오표 1~3차**(2025-08-29·10-31·12-23): 대부분 한글·영문·띄어쓰기 오류 수정이고, 코드 신설·삭제·행동양식 변경은 없다(MED-1685).
- **상병마스터**: 공공데이터포털의 2025-09-30판(47,798행)은 9차 신설 코드가 없는 9차 반영 전 파일이다(MED-1689).
  - 다음 등록 예정일은 2026-11-30이다(MED-1689).

## 3. 코딩 원칙 중 분쟁에 자주 인용되는 것

| 원칙 | 내용 | 근거 |
|---|---|---|
| 행동양식 | /0 양성, /1 경계성, /2 제자리, /3 악성. 색인과 의사 진단의 행동양식이 다르면 의사 진단 우선 | MED-1686 |
| D45~D47 | D45·D46·D47.1·D47.3~D47.5는 행동양식상 악성으로 볼 수 있으나 코드는 D37-D48 그대로 쓴다. 보험 분쟁에서 인용할 때는 두 부분을 모두 인용해야 한다 | MED-1686 |
| 재발·개인력 | 재발은 원발부위 C코드+U99, 원발 제거 후 치료가 끝났으면 Z85 | MED-1686, MED-1746 |
| 전이 | 전이 부위만 치료하면 전이가 주진단(크루켄베르그 C79.60·C79.61, 원발 위암은 기타진단) | MED-1746 |
| 주진단 | 검사 후 최종진단으로 입원하게 만든 가장 중요한 병태. 미확진이면 주증상·이상소견 | MED-1790 |
| 의심 진단 | 퇴원 진단이 '의심'이면 치료하지 않았을 때 증상 코드, 치료를 시작했을 때 의심 병태 코드 | MED-1790 |
| 심장 | STEMI(부위 미명시) I21.3, 스텐트 내 재협착은 합병증이 아닌 죽상경화 진행으로 I25.1+Z95.5, 이전 뇌경색 편마비는 후유증 I69.3 | MED-1748 |

- 기록의 주의: 코딩 원칙은 보험 약관의 '암 진단 확정'·'원발암 기준' 판단과 같지 않다(MED-1746).
  - 사례집 원칙을 근거로 "전이암이면 일반암 진단비를 못 받는다/받는다"고 말하지 않는다(MED-1746).
- 기록의 주의: 후유증 코드(I69.3)는 급성기 코드(I63)와 다르다. 보험 약관의 대상 코드 범위는 약관을 확인한다(MED-1748).

## 4. 코드를 둘러싼 분쟁 — 사례 짝

### 4-1. 약관이 인용한 KCD 차수

- 뇌·심장 코드가 9차에서 바뀌지 않았다는 점과 신생아 P코드 문제는 [뇌_심장_진단비_범위와_진단확정_가이드.md](뇌_심장_진단비_범위와_진단확정_가이드.md) 3절에 있다(MED-1684).

| 가입 당시 기준(소비자 유리) | 반대·한계 |
|---|---|
| 2018 [대법원]: 3차 KCD를 인용한 약관에서 1㎝ 미만 직장 유암종도 '암'이다(작성자 불이익)(MED-1611) | 2011 [분조위]: 혈구탐식성 림프조직구증은 6차 KCD에서도 악성으로 바뀌지 않아 다발성 소아암 대상이 아니다(MED-1793) |
| 2012 [분조위]: 4차 KCD로 '암'을 정한 약관이면 5차에서 경계성이 된 난소 종양도 암이다(MED-1636) | 게시 2026 [금감원 사례]: 각주에서 진단 시점 KCD를 기준으로 정한 보험도 있으니 약관을 확인하라고 했다(MED-1489) |
| 2011 [분조위]: 6차에서 악성(C96)으로 바뀐 질병은 적용 시점을 정하지 않은 약관이면 개정 전 진단에도 지급(MED-1794) | |

### 4-2. 약관이 정한 코드 범위 안인가

| 범위 안(지급) | 범위 밖(부지급) |
|---|---|
| 2015 [분조위]: 약관이 뇌졸중을 'I60~I63, I65~I66'으로 정했다면 파킨슨에 동반된 30% 경동맥 협착(I65.2)도 뇌졸중이다. 주진단이 아니거나 경미하다는 이유로 거절할 수 없다(MED-1695) | 2024 [금감원 사례]: 협심증(I20)은 급성심근경색증 진단비가 정한 I21~I23이 아니다(MED-1512) |
| 2011 [분조위]: 진단코드가 T84(인공삽입물 합병증)라도 무릎관절증 치료를 위한 재치환술이면 특정질병 수술자금 지급(MED-1812) | 2024 [금감원 사례]: 입원비 지급대상에서 정신장해(F00~F99)를 빼는 약관이면 신경증성 우울증(F34.1) 입원은 대상 아님(정액 입원비 사례)(MED-1516) |
| 2019 [분조위]: 원발부위가 갑상선인 림프절 전이(C77.0)는 일반암 치료비 대상(MED-1473) | 2011 [분조위]: 다발성 소아암 분류표에 없는 D76.1은 대상 아님(MED-1793) |

### 4-3. 면책 코드(선천성 기형 등)의 범위

| 면책 아님 | 면책 |
|---|---|
| 2010 [분조위]: 약관에 정의가 없으면 '선천성 뇌질환'은 KCD상 뇌의 선천기형(Q00~Q04)으로 제한 해석한다. 아놀드-키아리 증후군(Q07.0)은 면책이 아니다(MED-1824) | 2005 [분조위]: 2004년 약관이 '선천성 기형(Q00~Q99)' 전체를 면책하면, 10년 증상 없던 대동맥 축착(Q25.1)도 면책이다(MED-1850) |

- 기록의 주의(MED-1850): 이후 2009년 질병보험 표준약관은 '선천성 뇌질환' 면책을 Q00~Q04로 한정했다(MED-1824 판단). 현행 약관의 선천성 기형 면책 범위는 상품마다 다르다(MED-1850).
- 현행 실손 표준약관은 선천성 뇌질환(Q00~Q04)을 보상하지 않는 사항에 둔다. 가입 당시 태아인 경우의 예외는 기본형(급여)에만 있고, 비급여 특약1·2에는 없다(MED-1451, MED-2056).

### 4-4. 진단서 코드와 진단확정

- 2017 금감원 안내: 진단서에 C코드가 있어도 병리 진단 요건을 갖추지 못하면 암진단비가 지급되지 않을 수 있다(MED-1769).
- 2020 [대법원]: 이비인후과 전문의가 C41로 적은 진단서만으로는 고액암진단비 지급사유가 아니다(병리 전문의 요건 약관)(MED-1614).
- 2001 [분조위]: 담당의가 '뇌 악성신생물'을 '뇌 신생물'로 정정했고 조직검사가 D32.9면 암이 아니다(MED-1876).

## 확인 질문

1. 내 약관의 암·특정질병 분류표는 몇 차 KCD를 인용하나, '진단 시점 KCD'를 따르나(MED-1611, MED-1489)?
2. 약관이 대상 질병을 코드 범위(예: I60~I63)로 정했나, 병명으로 정했나(MED-1695, MED-1512)?
3. 진단서 코드가 주진단인가, 기타진단·후유증 코드인가(MED-1790, MED-1748)?
4. 형태분류(M코드)의 행동양식이 /1(경계성)인가 /3(악성)인가? 의사 진단은 무엇인가(MED-1686)?
5. 면책 조항이 코드 범위(Q00~Q99 등)를 명시했나, 병명만 적었나(MED-1824, MED-1850)?
6. 9차 개정 후 코드가 바뀐 질병인가? 순환계·뇌혈관 진단비 대상 코드는 번호가 바뀌지 않았다(MED-1684).

## 근거 없음 목록 (이 문서)

1. 9차 반영 심평원 상병마스터 원본(MED-1609는 partial이라 쓰지 않음)
2. 2025-12-23 이후 KCD 정오(4차 이후)
3. 진단 시점 KCD를 기준으로 정한 약관 원문
4. 수술분류표·질병분류표를 KCD 코드로 정한 현행 약관 원문
