# 보험금 청구 서류 떼는 법과 비용 가이드 (진단서·의무기록 사본·확인서)

- 기준일: 2026-11-02. 근거는 `status: verified` 기록이다(MED-2311).
- 법 조문은 의료법 2026-10-02 시행판, 의료법 시행규칙 2026-06-12 시행판이다. 수수료 상한은 보건복지부고시 제2021-34호(2021-02-05 시행, 2026-11-02 현재 현행) 기준이다(MED-2311, MED-2312, MED-2313).
- 보험금 청구 서류는 보험사·상품·사고마다 다르다. 아래 목록은 금융감독원 안내의 예시다(MED-2314).
- **내 청구에 어떤 서류가 필요한지는 가입 보험사에, 발급 비용은 병원 원무과에 확인한다**(MED-2314, MED-2313).
- 특정 병원을 다루지 않는다(MED-2313).
- 관련 자료(MED-2044)
  - 영수증 금액 구분, 실손이 보상하는 돈, 실손24 전자 청구는 [진료비_영수증_읽기와_실손_청구서류_가이드.md](진료비_영수증_읽기와_실손_청구서류_가이드.md)에 있다(MED-1752).
  - 청구 기한(3년)과 지급 지연이자는 [보험금_청구_기한과_소멸시효_가이드.md](보험금_청구_기한과_소멸시효_가이드.md)에 있다(MED-2044).
  - 영상 패키지: [66_진단서_의무기록사본_보험금청구서류_수수료상한](../packages/66_진단서_의무기록사본_보험금청구서류_수수료상한.md)(MED-2313).

## 1. 병원은 서류 발급을 거부할 수 없다

- 진단서는 직접 진찰한 의사·치과의사·한의사만 작성한다(MED-2311).
- **진찰받은 사람이 진단서를 요구하면 의사는 정당한 사유 없이 거부하지 못한다**(MED-2311).
- **환자 본인은 자기 진료기록 전부나 일부의 열람·사본 발급을 요청할 수 있고, 병원은 정당한 사유 없이 거부하지 못한다.** 고친 기록이면 수정 전 원본도 포함된다(MED-2311).
- 직접 진찰한 의사가 부득이하게 못 내주면 같은 병원의 다른 의사가 진료기록부를 근거로 내줄 수 있다(MED-2311).
- 기록을 보관하는 병원의 다른 의사도 과거 진료 내용을 기록을 근거로 확인해 줄 수 있다(MED-2311).
- 기록은 전자서명된 전자문서로 받을 수도 있다(MED-2311).
- '정당한 사유'가 무엇인지에 대한 해석·판례와 위반 시 벌칙은 이 저장소에서 확인하지 않았다(MED-2311).

### 보험회사는 직접 떼 갈 수 없다

- 의료법이 환자 동의 없이 기록을 줄 수 있게 정한 기관 목록에 민영 보험회사는 없다. 자동차보험 진료수가를 청구받은 보험회사만 예외다(MED-2311).
- 그래서 실손·생명보험 청구용 기록은 환자 본인이 받거나, 아래 2절의 서류를 갖춘 가족·대리인이 받는다(MED-2311).

## 2. 가족·대리인이 대신 뗄 때 필요한 서류 (시행규칙 제13조의3)

| 누가 | 필요한 서류 | 근거 |
|---|---|---|
| 환자 본인 | 본인 확인(병원이 본인인지 확인해야 함) | MED-2312 |
| 친족(배우자, 직계 존속·비속, 배우자의 직계 존속) | 요청자 신분증 사본 + 가족관계증명서 등 관계 서류 + 환자 자필서명 동의서(환자가 만 14세 미만이면 동의서 제외) | MED-2312 |
| 형제·자매 | 위 친족이 모두 없을 때만. 그 사실을 증명하는 자료를 더 냄 | MED-2312, MED-2311 |
| 환자가 지정한 대리인(친구·지인 등) | 요청자 신분증 사본 + 환자 자필서명 동의서 + 위임장 + 환자 신분증 사본 | MED-2312 |
| 환자가 사망·의식불명이라 동의를 못 받을 때 | 친족이 관계 증명서 등 별표 2의2 서류 | MED-2312, MED-2311 |

- 환자가 만 14세 미만이면 동의서·위임장은 법정대리인이 쓰고, 가족관계증명서 등 법정대리인 확인 서류를 붙인다(MED-2312).
- 주민등록증이 없는 만 17세 미만 환자는 환자 신분증 사본을 내지 않아도 된다(MED-2312).
- 친족은 신분증 대신 휴대전화 본인인증 등으로 본인 확인을 할 수 있다(MED-2312).
- 동의서는 별지 제9호의2서식, 위임장은 별지 제9호의3서식이다. 서식 본문은 이 저장소에서 읽지 않았다(MED-2312).
- 환자가 사망하거나 의식이 없으면 진단서는 직계존속·비속, 배우자, 배우자의 직계존속에게, 이들이 없으면 형제자매에게 내준다(MED-2311).

### 오래된 기록은 없어질 수 있다 (보존기간, 시행규칙 제15조)

| 기록 | 보존기간 | 근거 |
|---|---|---|
| 진료기록부, 수술기록 | 10년 | MED-2312 |
| 검사내용·검사소견기록, 방사선 사진(영상)·소견서, 간호기록부, 환자 명부 | 5년 | MED-2312 |
| 진단서 등의 부본 | 3년 | MED-2312 |
| 처방전 | 2년 | MED-2312 |

- 보존기간이 지난 기록은 병원이 없앨 수 있어 받지 못할 수 있다(MED-2312).
- 보험금 청구 기한(소멸시효)은 3년이다. 오래된 치료를 청구하려면 서류가 남아 있는지부터 확인한다(MED-2044, MED-2312).

## 3. 발급 비용 — 수수료 상한 (고시 제2021-34호, 2021-02-05 시행)

- 병원은 **0원부터 아래 상한금액 안에서** 자기 금액을 정해, 잘 보이는 곳과 홈페이지에 게시한다(MED-2313).
- 게시한 금액을 넘겨 받을 수 없다. 금액을 바꾸려면 14일 전까지 게시한다(MED-2313).
- 상한에는 진찰료·검사료가 들어 있지 않다. 진단서를 받으려고 진료를 받으면 진찰료가 따로 든다(MED-2313).
- 별표에 없는 서식(예: 보험사 양식 소견서)은 병원이 자체로 금액을 정할 수 있어 상한이 없다(MED-2313).

| 서류 | 상한금액 | 근거 |
|---|---|---|
| 일반진단서(영문 포함) | 2만 원 | MED-2313 |
| 사망진단서 | 1만 원 | MED-2313 |
| 상해진단서 3주 미만 | 10만 원 | MED-2313 |
| 상해진단서 3주 이상 | 15만 원 | MED-2313 |
| 후유장애진단서 | 10만 원 | MED-2313 |
| 입퇴원확인서·통원확인서·진료확인서 | 각 3천 원 | MED-2313 |
| 향후진료비추정서 | 1천만 원 미만 5만 원, 이상 10만 원 | MED-2313 |
| 진료기록사본 | 1~5매 1매당 1천 원, 6매부터 1매당 100원 | MED-2313 |
| 진료기록영상 | 필름 5천 원, CD 1만 원, DVD 2만 원 | MED-2313 |
| 제증명서 사본(재발급) | 1천 원 | MED-2313 |
| 시체검안서 | 3만 원(출장비 제외) | MED-2313 |

- 같은 증명서를 한 번에 여러 통 받으면 첫 통 외에는 사본(1천 원)으로 본다(MED-2313).

## 4. 청구할 때 필요한 서류 — 금감원 안내 예시

| 청구 | 서류 예시 | 근거 |
|---|---|---|
| 모든 청구 공통 | 보험사 청구서, 신분증 사본(수익자 본인이 아니면 수익자 인감증명서) | MED-2314 |
| 입원 | 진단서, 입·퇴원 확인서 | MED-2314 |
| 수술 | 진단서, 수술확인서 등 | MED-2314 |
| 진단 | 진단서, 진단사실 확인 서류 | MED-2314 |
| 장해 | 후유장해 진단서 | MED-2314 |
| 사망 | 사망진단서(시체검안서) 원본, 기본증명서(사망 사실 기재) | MED-2314 |

- 청구서·개인신용정보동의서·신분증·계좌번호는 모두 수익자 기준으로 낸다(MED-2314).
- 미성년 수익자는 친권자(후견인)가 청구하고, 미성년자 기준 기본증명서·가족관계증명서를 낸다(MED-2314).
- 재해사고는 사고사실 확인서 등 재해 입증 서류가 더 필요할 수 있다(MED-2314).
- 암·급성심근경색·뇌출혈 같은 중대질병 진단은 진료기록 사본 외에 검사결과 같은 진단 근거를 더 요청받을 수 있다(MED-2314).
- 표준약관의 청구 서류는 청구서, 사고증명서(진료비계산서·입원치료확인서·처방전 등), 신분증(대리 시 인감증명서 등)이다(MED-2044).

### 100만 원 이하는 사본으로

- **소액보험금(100만 원까지)은 진단서 등을 원본이 아닌 사본으로 청구할 수 있다**(MED-2314).
- 같은 내용은 2017년 금감원 안내에도 있다. 사본은 온라인·앱·우편·팩스로 낼 수 있는 보험사가 대부분이라고 했다(MED-2050).
- 원본 한 통을 받아 두고 사본(재발급 1천 원)이나 복사본을 쓰면 여러 보험사에 낼 때 비용이 줄 수 있다. 회사가 사본을 받는지는 먼저 묻는다(MED-2313, MED-2314).

### 소액 통원 실손은 진단서 없이 — 2015년 합의 기준

**아래 금액은 2015-01 시행 당시 업계 합의 기준이다. 지금도 같은지, 표준약관에 들어갔는지는 확인하지 못했다**(MED-2315).

| 통원의료비 | 서류(2015-01 시행 당시) | 근거 |
|---|---|---|
| 3만 원 이하 | 보험금 청구서 + 병원영수증 | MED-2315 |
| 3만 원 초과 10만 원 이하 | 보험금 청구서 + 병원영수증 + 처방전(질병분류기호 기재), 진단서 불필요 | MED-2315 |

- 지급 제외 대상이 많은 진료과목(산부인과·항문외과·비뇨기과·피부과)이나 짧은 기간 잦은 청구는 추가 서류를 요청받을 수 있다(MED-2315).
- 실손24로 청구하면 영수증·진료비 세부산정내역서·처방전을 병원이 보험사로 바로 보낸다. 연계되지 않은 병원은 서류를 직접 낸다(MED-1752).

### 진단서 대신 확인서로 되는 경우

- 금감원 예시상 입원 청구는 진단서와 입·퇴원 확인서를 함께 낸다. 확인서가 진단서를 대신한다는 안내는 근거 자료에 없다(MED-2314).
- 근거 자료에서 진단서가 빠지는 경우는 소액 통원(2015년 합의, 처방전에 질병분류기호)뿐이다(MED-2315).
- 진단서(상한 2만 원)와 진료확인서(상한 3천 원)는 비용 차이가 크다. 질병코드가 적힌 진료확인서로 받아 주는지는 근거 자료에 없으니 떼기 전에 보험사에 묻는다(MED-2313, MED-2314).

## 5. 언제 받나 — 지급 기한

| 기준 | 지급 기한 | 근거 |
|---|---|---|
| 표준약관 | 서류를 받은 날부터 3영업일 안. 조사가 필요하면 30영업일 안의 지급예정일을 알리고, 가지급(50% 이내) | MED-2044 |
| 금감원 소비자 안내 화면 | 청구 접수일부터 3영업일 안이 원칙(일부 상품군 다름), 조사·확인이 필요하면 10영업일 안 | MED-2314 |

- 조사가 필요할 때의 기한은 두 자료가 다르다. 계약 기준인 약관을 먼저 본다(MED-2314, MED-2044).
- 보험사는 접수하면 접수번호와 담당자를 문자로 알린다(MED-2314).

## 체크리스트

1. 보험사에 내 청구에 필요한 서류 목록을 먼저 물었나(MED-2314)?
2. 청구액이 100만 원 이하라면 사본으로 낼 수 있는지 확인했나(MED-2314)?
3. 소액 통원이라면 진단서 없이 영수증·처방전(질병분류기호)으로 되는지 물었나(MED-2315)?
4. 병원 원무과·홈페이지에 게시된 발급 수수료를 확인했나(MED-2313)?
5. 같은 서류가 여러 통 필요하면 두 번째부터 사본(1천 원)으로 받았나(MED-2313)?
6. 가족이 대신 뗀다면 신분증 사본, 관계 서류, 환자 자필 동의서(대리인은 위임장과 환자 신분증 사본까지)를 챙겼나(MED-2312)?
7. 오래된 치료라면 기록 보존기간(처방전 2년, 검사기록 5년, 진료기록 10년)이 지나지 않았나(MED-2312)?
8. 실손24 연계 병원이면 앱으로 청구했나(MED-1752)?

## 근거 없음·확인 안 됨 목록 (이 문서)

1. 의료법상 '정당한 사유'의 해석과 거부 시 벌칙(MED-2311)
2. 동의서·위임장 서식 본문과 사망·의식불명 시 친족 서류(별표 2의2)(MED-2312)
3. 소액 통원 서류 간소화 금액(3만·10만 원)의 현재 기준과 표준약관 반영 여부(MED-2315)
4. 진단서 대신 진료확인서를 받아 주는 기준(MED-2314)
5. 병원별 실제 발급 수수료 평균(MED-2313)
6. 제정과 현행 사이 고시 개정에서 금액이 바뀌었는지(MED-2313)

**최종 판단은 가입 보험사·병원 원무과에서 확인한다**(MED-2314, MED-2313).
