# 영상 원고 팩트체크 도구 (tools/)

영상 원고 속 숫자를 숫자 카드표(`numbers/numbers.csv`)와 근거 기록(`sources/`)의 '핵심 근거' 절에서 찾아, 문장마다 판정을 붙인 표를 만든다. 2026-10-18 작성(Claude Code). 파이썬 표준 라이브러리만 쓴다.

| 파일 | 내용 |
|---|---|
| `factcheck.py` | 팩트체크 스크립트 |
| `examples/` | 시험 원고 3개와 결과 |

## 쓰는 법

```bash
python -X utf8 medical/tools/factcheck.py 원고.txt > 결과.md
```

- 원고는 `.txt`나 `.md` 파일이고 UTF-8이어야 한다. 한 줄에 여러 문장이 있어도 마침표 기준으로 나눈다. 목록 기호(`-`, `1.`)와 굵게 표시(`**`)는 지우고 읽는다.
- `#`으로 시작하는 줄(제목)은 판정하지 않는다. 그 아래 문장들의 맥락(어떤 질병·제도 이야기인지)으로만 쓴다. 원고에 질병 이름이 문장마다 없으면 제목에 적어 두면 근거 순서가 나아진다.
- 문장 끝에 붙은 `(MED-NNNN)` 괄호는 숫자로 읽지 않는다.
- 옵션
  - `--today 2026-12-01`: 재확인 기한을 그날 기준으로 본다(기본: 실행한 날).
  - `--detail`: 숫자마다 근거 후보를 최대 3개까지 보인다(기본 1개).
- 실행에 10~20초 걸린다(기록 1,900여 건을 매번 읽는다).

## 결과 표 읽는 법

맨 위에 판정별 문장 수가 나오고, 그 아래 표가 문장 하나에 한 줄이다.

| 열 | 내용 |
|---|---|
| 문장 | 원고 문장 |
| 뽑은 숫자 | 판정한 숫자. 연도·날짜·단위 없는 작은 수는 맥락으로 함께 적지만 판정하지 않는다 |
| 판정 | 문장 안 숫자 중 가장 나쁜 판정 |
| 근거(숫자별) | 숫자마다 판정과 근거 1개: 카드번호·기록번호(status·tier·재확인 기한), ⚠ 주의 표시, 근거 문장 앞부분. '외 N건'은 같은 숫자가 나온 다른 근거 수 |

## 판정 기준

숫자 하나마다 아래 순서로 찾는다.

1. **카드**: `numbers.csv`에서 값·단위가 같은 카드(한 줄 문장에 풀어 쓴 값 포함)를 찾는다. 카드의 주제·한 줄 문장·기준시점과 원고 문장이 단어를 1개 이상 공유해야 한다.
2. **기록**: 카드가 없으면 `sources/`의 모든 기록(superseded·rejected 제외) '핵심 근거' 절에서 값·단위가 같은 숫자를 찾는다. 그 숫자가 있는 문장과 원고 문장이 단어를 1개 이상 공유해야 한다.
3. 두 경우 모두, 원고 문장에 질병·제도 이름(예: 위암, 실손, 도수, 상한액, 투석 등 약 60묶음, `factcheck.py`의 `ENTITIES`)이 있으면 근거 쪽에도 같은 묶음의 이름이 있어야 일치로 본다.

| 판정 | 뜻 |
|---|---|
| 근거 있음(카드) | 주의 표시가 없는 카드에서 찾았다 |
| 근거 있음(기록) | 카드는 없고, 주의 표시가 없는 기록 '핵심 근거'에서 찾았다 |
| 주의 | 찾았지만 가장 알맞은 근거에 아래 표시 중 하나 이상이 붙었다 |
| 근거 없음 | 카드에도 기록에도 같은 숫자가 없다(또는 숫자는 같아도 단어·이름이 겹치지 않는다) |
| 숫자 없음 / 숫자 없음(연도·날짜만) | 판정하지 않는다. 사람이 확인한다 |

'주의' 표시의 종류:

| 표시 | 언제 |
|---|---|
| `status partial` 등 | 근거 기록이 verified가 아님(index.csv의 status) |
| `tier C` | 해외·보조 자료(국내 제도 근거로 쓰지 않음) |
| `재확인 기한 지남(날짜)` | index.csv의 recheck_by가 기준일보다 이름 |
| `직접 계산` | 카드 주의 열이나 기록 문장에 '직접 계산·직접 합산'이 적힌 값 |
| `미검증 절에 같은 숫자: …` | 같은 숫자가 그 기록의 '미검증·사용 금지' 절 문장에 있고, 그 문장이 원고 문장과 단어를 공유함. 표시 옆에 그 문장을 보인다 |
| `기록이 수치 사용을 제한` | '미검증·사용 금지' 절에 '원 발표 대조 전 … 수치를 쓰지 않는다'처럼 기록 전체의 수치를 막는 문구가 있음 |
| `단위 표기 없는 값과 일치(단위 확인)` | 원고는 '7,435천 명'인데 기록은 표 머리에만 단위를 적고 '7,435'로 쓴 경우. 단위가 맞는지 사람이 본다 |

숫자 읽기 규칙:
- `7만 8,979건`, `1조 1,571억 원`, `5,508천 원`, `550만 8천 원`처럼 큰 단위를 섞어 써도 같은 값으로 본다(5,508천 원 = 550만 8천 원).
- `30~40%`, `90만~843만 원` 같은 범위는 두 값이 모두 같아야 일치다.
- `100분의 40`은 40%로 읽는다.
- 연도(1990~2099년), 날짜(2026-07-01, 7월 1일), 고시·판례 번호, MED·N 번호, 상병·행위 코드(C16, O7020), 비율 표기(2.0:1), '1인실·2형·3세대'처럼 이름에 붙은 숫자는 판정하지 않는다.
- '약'은 무시하고 값만 비교한다. 원고가 반올림한 값(예: 1조 1,684억 8,572만 원을 '약 1조 1,685억 원'으로)은 '근거 없음'이 나온다.

시험 2에서 바꾼 숫자: 28,943건→29,843건, 78.6%→76.8%, 157,759명→175,759명, 위암 보장률 72.8%→78.2%, 1,496,952명→1,469,952명, 45,455명→45,545명, 126,944명→129,644명, 도수치료 43,850원→48,350원, 7,359,281명→7,395,281명, 혈액투석 5년 생존율 80.2%→82.0%, 9,812억 원→9,182억 원.

시험 1의 '근거 없음' 8개:
- 제대로 잡은 것 3개(패키지 쪽을 고칠 후보)
  - '1~2%p 변화는 오차 범위': 패키지 작성자의 해석이라 기록에 숫자가 없다.
  - 혈액투석 '실시 1,042만 회'·'약 1조 1,685억 원': 기록 원문은 10,424,188회·1,168,485,720천 원이고, 패키지가 반올림했다(15_만성콩팥병_투석 3절).
- 놓친 것 5개(참인데 '근거 없음')
  - 위암 '60대 32.9%', 투석 '65세 이상 45.1%': 원고 문장과 근거 문장이 공유하는 단어가 없었다('이상'·'가장' 같은 흔한 말은 단어로 치지 않는다).
  - 위암 검진 '40~74세'·'75세': 원고 문장의 '국가검진'이라는 이름이 근거 기록(검진 권고안) 문장에 없었다.
  - '13개 만성질환': 원고 문장의 '만성신부전증' 이름이 근거 문장에 없었다.

근거로 고른 기록이 패키지 원문에 붙어 있던 MED 번호와 같은지도 대조했다. 근거를 표시한 숫자 144개 중 122개가 같았다. 나머지 22개 가운데 다수는 같은 사실이 다른 기록에도 있는 경우(예: 암 산정특례 5%를 MED-0010 대신 고시 MED-0104로, 1,496,952명을 MED-1734 대신 MED-1545로)였다. 그러나 '5년'·'65세'·'2회'·'50%'처럼 흔한 작은 숫자 6개 안팎은 주제가 다른 기록을 근거로 골랐다.

## 한계

- **숫자 일치만 본다. 문장 뜻이 근거와 같은지는 사람이 확인해야 한다.** 숫자와 단어 몇 개가 겹치면 '근거 있음'이 나오므로 다음을 잡지 못한다.
  - 대상·연도·기준을 바꿔 쓴 문장(예: 2023년 값을 2024년이라고 쓴 경우)
  - 남녀·연령·병기를 바꿔 쓴 문장
  - '진료비'를 '치료비 전체'로, '생존율'을 '완치율'로 바꿔 쓴 문장
- '5년', '65세', '2회', '50%'처럼 흔한 작은 숫자는 주제가 다른 기록과도 맞아 떨어질 수 있다. 이런 숫자의 '근거 있음'은 근거 문장을 꼭 열어 본다.
- 반대로 참인 숫자가 '근거 없음'으로 나올 수 있다(시험 1에서 152개 중 5개). 원고 문장이 근거 문장과 단어를 공유하지 않거나, 원고 문장의 질병·제도 이름이 근거 문장에 없을 때다. '근거 없음'이 나오면 저장소에서 직접 찾아본 뒤 판단한다.
- 반올림·환산한 값(약 1,500만 원, 2.3배, '3명 중 1명')은 근거 원문에 같은 글자가 없으면 '근거 없음'이다. 계산이 맞는지는 보지 않는다.
- 범위 끝값 하나만 쓴 문장(예: '상한액 최고 843만 원')은 그 값이 단독으로 적힌 근거가 있어야 찾는다.
- 날짜·연도·고시 번호·판례 번호는 판정하지 않는다. 시행일·연도가 맞는지는 사람이 본다.
- 숫자가 아닌 카드 7장(N-0114·0213·0255·0258·0259·0260·0324: 시행일·'간암' 같은 값)은 이 도구로 찾지 않는다.
- '미검증 절에 같은 숫자' 표시는 같은 숫자가 해석 제한 문구에 나온 경우도 잡는다(예: 보장률 64.9%를 '정체'로 말하지 말라는 문구). 표시 옆 문장을 읽고 판단한다.
- '주의'가 아니어도 출처 기록의 `적용 조건·한계` 절과 카드의 주의 열은 따로 읽어야 한다. 이 도구는 그 내용을 판정에 쓰지 않는다.
- 질병·제도 이름 묶음(`ENTITIES`)은 손으로 만든 목록이다. 새 질병·제도를 다루는 원고면 목록에 추가해야 정확해진다.
