## 원고 형식

- **머리말**: 출처(패키지 7절 각도나 CALENDAR.md 일정), 시의성, 목표 길이, 새 통계·공고가 나오면 고칠 문장 번호, 작성일.
- **근거 표시판**: 번호를 매긴 문장마다 끝에 `(MED-NNNN)`을 붙인다.
- **낭독판**: 근거 표시판과 같은 문장에서 번호만 뺀 것이다. 문장을 고치면 두 판을 함께 고친다.

## 작성 규칙

- `status: verified` 기록만 인용한다. 숫자는 인용한 기록의 핵심 근거 절에 있는 값을 쓴다. 계산값에는 '약'이나 '평균 …인 셈'을 붙인다.
- 기록의 미검증 절에 적힌 '쓰지 않는다'·'단정하지 않는다'를 지킨다(예: 할인율 예시를 확정값처럼 말하지 않음, 확인되지 않은 대상 진료를 예로 들지 않음).
- 결정이 갈리는 쟁점은 양쪽 결정을 함께 쓴다.
- 길이는 45~55초다. 공백을 뺀 낭독판 기준 약 330~390자로 맞췄다.
- 첫 문장은 질문보다 일정·사실로 시작한다. 싸움을 유도하는 문단은 넣지 않는다. 마지막은 '내 돈으로 보면 …확인해 보세요'로 맺는다(`~/.claude/skills/finance-shorts-local/retention-considerations.md` 참고, 확정 규칙 아님).
- 점검: `python -X utf8 tools/factcheck.py packages/drafts/<원고>.md`에서 '근거 없음'과 '인용 번호 불일치'가 0이어야 한다. 낭독판 문장은 MED 번호가 없어 숫자 카드와 단어가 겹쳐야 근거를 찾는다. '근거 없음'이 나오면 병명이나 항목 이름을 문장에 넣는다.
