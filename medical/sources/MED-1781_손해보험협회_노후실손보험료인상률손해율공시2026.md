## 핵심 근거
- **기본형 합계 인상률(2026년 / 2025년 / 2024년)**: 메리츠 15.8 / 17.4 / 15.4%, 롯데 8.4 / 5.6 / 14.8%, 삼성화재 18.5 / 5.7 / 8.8%, 현대해상 0.2 / 22.1 / 7.7%, KB 14.0 / 14.6 / -4.5%, DB 3.3 / 8.7 / 24.4%, 농협손보 10.2 / 1.5 / 11.0%, 한화생명 20.6 / -0.3 / -8.4%, 삼성생명 18.8 / 2.3 / 19.9%.
- **기본형 합계 손해율(2025년 / 2024년 / 2023년)**: 메리츠 78.4 / 81.4 / 82.2%, 롯데 71.4 / 78.0 / 60.2%, 삼성화재 66.1 / 71.3 / 69.2%, 현대해상 80.5 / 89.6 / 83.6%, KB 93.8 / 84.6 / 102.8%, DB 67.2 / 75.7 / 81.6%, 농협손보 93.5 / 123.6 / 89.4%, 한화생명 91.2 / 54.7 / 50.0%, 삼성생명 65.8 / 63.5 / 53.4%.
- 요양병원 의료비·상급병실료 차액 담보는 손해율이 낮은 회사가 많지만(예: DB 상급병실료 25.0%) KB 요양병원 의료비 2025년 335.8%처럼 튀는 값도 있다.

## 적용 조건·한계
- 노후실손은 고령자 전용 상품이라 표준화실손(MED-1780)보다 손해율이 낮게 나오는 회사가 많다. 회사·담보마다 차이가 커서 평균 내지 않는다.

## 미검증·사용 금지
- 업계 평균은 없다. 2027년 값은 아직 없다.

## 영상 활용 메모
- '노후실손도 2026년에 회사에 따라 0~20%대 인상' 같은 보조 설명용.
