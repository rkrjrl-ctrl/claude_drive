## 핵심 근거
- **성별 업무상 질병 승인율(승인÷신청 또는 처리, 계산)**

  | 연도 | 남성 | 여성 | 질병 신청(처리) 중 여성 비중 |
  |---|---|---|---|
  | 2017 | 51.4% | 50.4% | 14.3% |
  | 2018 | 60.4% | 54.9% | 15.0% |
  | 2019 | 60.8% | 59.8% | 17.4% |
  | 2020 | 61.9% | 59.0% | 18.5% |
  | 2021 | 63.7% | 60.5% | 17.6% |
  | 2022 | 62.6% | 63.0% | 18.0% |
  | 2023 | 58.4% | 55.4% | 17.0% |

  - 2023년 질병: 남성 신청 26,276건·승인 15,345건, 여성 신청 5,390건·승인 2,988건. 사고: 남성 92,177건·88,701건, 여성 39,104건·37,931건.
  - 2017~2020 판에는 산재보험 피보험자 수도 있다(2019년 남 10,890,570명·여 9,169,801명).
- **업종별 산재 신청 / 승인 / 승인율(사고·질병·출퇴근 합계)**
  - 금융 및 보험업: 2018년 525 / 439 / 83.6% → 2020년 531 / 428 / 80.6% → 2022년 962 / 824 / 85.7% → 2024년 980 / 833 / 85.0%.
  - 광업: 2018년 2,875 / 1,389 / 48.3% → 2022년 5,013 / 2,951 / 58.9% → 2024년 3,472 / 1,928 / 55.5%. 업종 중 승인율이 가장 낮다(진폐 등 질병 신청 비중이 큰 업종으로 보이나 이 자료로는 확인 불가).
  - 2024년: 제조업 40,439 / 34,128 / 84.4%, 건설업 38,932 / 34,261 / 88.0%, 운수·창고·통신업 19,598 / 17,723 / 90.4%, 기타의 사업 67,458 / 61,020 / 90.5%.
- **규모별(2024년, 신청 / 승인 / 승인율):** 5인 미만 41,277 / 36,784 / 89.1%, 5~30인 미만 45,219 / 40,112 / 88.7%, 30~50인 12,869 / 11,268 / 87.6%, 50~100인 13,446 / 11,573 / 86.1%, 100~300인 15,256 / 12,977 / 85.1%, 300~500인 6,818 / 5,643 / 82.8%, 500~1000인 8,104 / 6,734 / 83.1%, 1000인 이상 30,614 / 26,662 / 87.1%. 30인 미만 사업장이 신청의 약 50%(계산).

## 적용 조건·한계
- 업종별·규모별은 사고·질병·출퇴근을 합친 값이다. 업종별 질병 승인율은 이 자료로 알 수 없다.
- 업종 이름 표기가 해마다 조금씩 다르다(띄어쓰기 등). '구분 없음'은 승인 0건으로 집계돼 있다.

## 미검증·사용 금지
- 성별 파일 2024년 이후 판 미확보(최신 20231231).
- 업종별·성별 질병 유형 내역 미확보(업무상 질병 승인 원자료 MED-1227로 일부 집계 가능).

## 영상 활용 메모
- '금융·보험업 산재 신청도 6년 새 거의 2배(525건 → 980건), 85%가 승인' — 사무직도 산재 대상이라는 소재. 사고·질병 합계임을 밝힌다.
- '직업병 산재, 여성은 신청의 17% — 승인율은 남녀 비슷(2023년 58% 대 55%)' 소재.
