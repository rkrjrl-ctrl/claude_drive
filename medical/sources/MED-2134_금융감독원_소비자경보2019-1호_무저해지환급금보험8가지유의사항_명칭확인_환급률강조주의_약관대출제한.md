## 핵심 근거
- 대상: 상품 명칭에 '해지환급금 미지급(일부 지급)', '무(저)해지환급' 등이 들어간 보험(예: ○○질병보험[해지환급금 일부지급형], (무)○○종신보험(무해지환급형)).
- 발령 배경: 신계약 2016년 32.1만 → 2017년 85.3만 → 2018년 176.4만 → 2019년 1~3월 108.0만 건. 초기엔 암·건강·어린이보험, 최근엔 보험기간이 긴 종신·치매보험 중심. **납입기간 20년 이상이 대부분(생보 58%, 손보 71%)**이라 경기 침체로 해지가 늘면 민원 급증 가능성.
- **8가지 유의사항**: ① 상품명으로 무(저)해지 여부 확인 ② 상품설명서의 일반상품 대비 보험료·기간별 해지환급금 비교 확인 ③ 납입 완료 전 해지 시 환급금이 없거나 적음을 상품안내자료·계약자확인서로 확인 ④ 보험료가 저렴하다는 점만 강조하면 유의 ⑤ **납입기간 이후 환급률만 강조하면 유의** ⑥ **종신·치매보험은 목돈·연금 목적에 부적합**(노후 대비는 연금보험) ⑦ **납입기간 동안 보험계약대출이 불가능하거나 제한적** ⑧ 만기까지 유지하면 저렴한 보험료로 같은 보장을 받아 유리하지만, 중도해지 시 납입 보험료를 전혀 돌려받지 못할 수 있음 — 이미 가입했다면 만기까지 유지할 필요.
- 사례: 무해지 종신(20년납)을 적금처럼 권유받아 가입 후 3년 만에 실직해 해지 → 환급금 0원 / 연금보험처럼 권유받아 5년 뒤 해지·약관대출 문의 → 환급금·대출 모두 불가 / 보험료 20% 낮고 환급률 높다는 설명만 듣고 가입 → 5년 뒤 해지 시 0원.
- 향후: 판매 보험사에 경보 내용 설명 지도, 민원 증가 시 현장조사·부문검사.
