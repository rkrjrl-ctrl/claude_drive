## 핵심 근거
- **샤임프러그 사진촬영[편측][분석 포함] 2025(곳 / 변동계수 / 최소/최대/중간/평균, 천 원)**: 전체 95곳 / 151.8 / 5/2,000/66/126. 병원급 40곳 / 48.5 / 5/165/57/59. 상급종합 24곳 / 35.3 / 5/125/64/64. 종합병원 12곳 / 44.4 / 7/105/53/52. 병원 4곳 / 73.9 / 20/165/40/55. **의원급 55곳 / 142.3 / 10/2,000/100/158**.
- 보도자료 본문: 2025년 신규 공개 항목 중 백내장 등 안과질환 진단에 쓰는 샤임프러그 사진촬영 검사의 기관별 가격 편차가 컸다.
- **간섭에 의한 눈물지질층 두께 측정 2025**: 전체 149곳 / 106.4 / 5/400/38/52. 병원급 38곳 / 60.9 / 12/200/44/45. 상급종합 18곳 / 12/81/50/47. 의원급 111곳 / 115.2 / 5/400/30/55.

## 적용 조건·한계
- 신규 항목이라 전년 비교가 없다. 제출 기관 수가 적어(95·149곳) 평균이 극단값에 크게 흔들린다.
- 백내장 수술 자체는 포괄수가 급여, 다초점 렌즈는 비급여 치료재료다(MED-1418). 이 검사는 그와 별개 항목이다.

## 미검증·사용 금지
- 의원 사례 최대 200만 원은 단일 기관 값이라 '보통 가격'으로 쓰지 않는다.
- 2026년 공개분의 같은 항목 값은 조회하지 않았다.

## 영상 활용 메모
- 백내장·실손 분쟁 소재에서 "같은 검사가 의원마다 5천 원~200만 원" — 가격 편차 장면(기관명 없이).
