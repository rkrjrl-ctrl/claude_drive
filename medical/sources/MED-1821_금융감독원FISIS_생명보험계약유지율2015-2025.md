## 핵심 근거
- **대형사 25회차 유지율(2015 → 2019 → 2023 → 2025년)**: 삼성생명 73.11 → 60.98 → 65.53 → 77.24%, 한화생명 67.19 → 60.13 → 59.20 → 75.11%, 교보생명 67.38 → 63.92 → 46.83 → 74.97%, 신한라이프 58.69 → 66.20 → 63.02 → 75.61%, 농협생명 80.92 → 61.79 → 69.05 → 83.62%.
- **13회차 유지율(2025년)**: 농협 92.56%, 처브 91.71%, iM라이프 91.76%, IBK연금 91.20%, DB 91.13%가 높고, BNP파리바카디프 68.53%, 미래에셋 79.45%, AIA 81.26%, 라이나 81.81%가 낮다.
- **2023년 일시 급락**: 교보생명 25회차 46.83%, 흥국생명 45.54%, 교보라이프플래닛 28.36%처럼 2023년에 크게 떨어졌다가 2024~2025년 회복한 회사가 여럿이다(원인은 표에 없음).
- **장기 개선 사례**: 처브라이프 25회차 35.93%(2015) → 80.12%(2025), ABL생명 42.73% → 79.08%.

## 적용 조건·한계
- FISIS 업무보고서 기준이며 협회 공시(MED-1659, 반기·보험료 기준)·금감원 연간 보도자료(MED-1656)와 산출 기간·기준이 다를 수 있다.
- 37·61회차 장기 유지율은 이 표에 없다.

## 미검증·사용 금지
- 2023년 급락 원인(일회성 해지, 산출 기준 변경 등)을 추정해 말하지 않는다.
- 업계 평균을 직접 내지 않았다.

## 영상 활용 메모
- '대형 생보사 2년 유지율은 10년 내내 60~77%대, 4건 중 1건 안팎은 2년 안에 깨진다' 장면에 쓴다. 회사 비교는 연도마다 크게 바뀌므로 추이로만 보여 준다.
