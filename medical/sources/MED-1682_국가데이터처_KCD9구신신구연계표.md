## 핵심 근거
- **신생물(제Ⅱ장)에서 바뀐 코드는 D37 두 곳뿐**이다.
  - D37.6 간, 담낭 및 담관의 행동양식 불명 또는 미상의 신생물 → **D37.60 간, D37.61 담낭, D37.62 담관, D37.63 파터팽대, D37.68 기타 및 상세불명의 간담도계**.
  - D37.7 기타 소화기관의 행동양식 불명 또는 미상의 신생물 → **D37.70 췌장, D37.78 기타 명시된 소화기관**.
  - 그 밖의 C00-D48 코드는 연계표에 신설·삭제·이동 행이 없다.
- **순환계(제Ⅸ장)**: I20.88 기타 형태의 협심증 → I20.81 안정협심증·I20.88로 분리. I50.1 좌심실부전 → I50.10(박출률 정상)·I50.11(중간범위)·I50.12(감소)·I50.19(상세불명). I50.04(수축기능부전 동반 울혈성 심부전)·I50.05(수축기능 정상 울혈성 심부전)는 대응 코드 없음('-')으로 삭제. **뇌혈관(I60-I69)은 연계표에 행이 없다.**
- **그 밖의 대응**: A08.38 → A08.32·A08.38, B34.2 → B34.20(MERS)·B34.28, E83.4·E83.5 세분, F32.2 → F32.20·F32.21(치료저항성), G35·G47.2, J82.8 → J82.1 호산구성 천식 분리, J84.1, K29.6 → K29.60(위의 장상피화생)·K29.68, K57의 '출혈 동반/비동반 게실염' 5단위(K57.x2·x3) → 게실염(x4)으로 통합, K82.88·K83.0·K86.1, L63.8, O34 임신 주수 세세분류 전부 삭제, S01.4 → S01.40~S01.48, U07.3~U07.9·U18·U18.0 삭제(MERS는 B34.20), 한의병명 U22-U32 → U86-U87, K56.6의 '관격' → U87.8, U95.4~U98.2 등 사상체질 코드 정비.

## 적용 조건·한계
- 연계표는 통계 시계열용이며 개별 진단의 코드 결정은 분류표·지침서를 따른다(표 머리 주의문).
- 건강보험 청구 상병마스터에 9차가 반영된 원본은 확보하지 못했다(MED-1609·1689).
- 민영보험의 암·특정질병 분류표는 약관이 인용하는 차수를 따른다. 9차 코드가 생겼다고 바로 보장 대상이 바뀌는 것은 아니다(MED-1610).

## 미검증·사용 금지
- 2025-12-23 현재판이다. 이후 정오표로 바뀔 수 있다(MED-1685).
- 오기(I51.10)가 있는 행은 원문 표기 그대로 인용하지 않는다.

## 영상 활용 메모
- 췌장·담도 쇼츠: "2026년부터 '행동양식 불명 신생물' 코드가 췌장(D37.70)·담낭(D37.61)·담관(D37.62)으로 나뉘었다" — 진단서 코드 읽기 팁.
- 협심증: 안정협심증 전용 코드 I20.81 신설. 특약 판단은 약관 확인 전제로만.
