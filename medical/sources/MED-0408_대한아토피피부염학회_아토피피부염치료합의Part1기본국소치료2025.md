## 핵심 근거
- 방법: 한국 아토피피부염 치료 전체를 48개 질문으로 정리한 표 1이 이 논문에 있으며, 본문 해설은 기본치료·국소치료·기존 전신치료까지다. 표기는 권고등급(A 강함, B 약함·선택적, C 약함·제한적 사용, D 강한 반대) / 근거수준(1a~5) / 학회원 동의율.
- 기본치료:
  - 보습제 사용 권고, 급성 악화 예방과 증상 개선(A / 1a / 98%). 급성 염증 병변에 보습제 단독으로 쓰지 않고 필요시 항염증 치료와 병용한다고 서술. 향료 없는 저자극 제품 선택, 영아 일차 예방 효과는 근거가 엇갈려 추가 확인 필요.
  - 집먼지진드기 감작이 있고 노출과 연관된 뚜렷한 악화 이력이 있는 환자에서 진드기 회피 제안(B / 2b / 94%). 일차 예방 목적으로는 권고하지 않는다. 털 있는 동물 회피는 알레르기가 확인된 경우에 한하고 예방 목적만으로는 권고하지 않는다. 식이 제한은 전문의가 진단한 식품 알레르기에 한해 권고하고 일반적 제한식은 권고하지 않는다.
  - 다학제 의료진이 참여하는 구조화된 교육 프로그램 권고(A / 1b / 94%), 잘 구성된 교육 자료를 이용한 환자 교육 제안(B / 2b / 92%). 스테로이드 공포증이 순응도를 떨어뜨린다고 서술. 세정·목욕 권고(미온수 등)는 보충자료에 있다.
- 국소치료:
  - 국소 스테로이드 사용 권고(A / 1a / 100%), 중증도·부위·연령에 맞는 강도 선택 권고(A / 1a / 100%). 급성 악화에서 초기 집중 치료 후 점차 줄이고, 재발이 반복되면 선제(proactive) 치료를 권고하며, 얼굴·눈꺼풀 등 부위에서는 장기 사용 부작용(피부 위축 등)에 유의한다고 서술.
  - 급성 악화 병변에 희석 국소 스테로이드와 습포(wet wrap) 요법 고려 제안(B / 1b / 92%).
  - 국소 칼시뉴린 억제제 사용 권고(A / 1a / 96%), 얼굴·접힘 부위·생식기 등 민감 부위에 사용 권고(A / 1b / 98%), 작열감 감소를 위해 먼저 국소 스테로이드를 쓴 뒤 전환 제안(B / 5 / 72%). 본문은 FDA의 암 위험 경고 문구가 있으나 장기 연구에서 의미 있는 악성종양 증가는 없었다고 서술하며 추가 감시가 필요하다고 한다.
  - 호전된 부위의 재발 방지를 위해 중등도 강도 국소 스테로이드 또는 칼시뉴린 억제제를 주 2~3회 선제 사용 권고(A / 1a / 94%).
- 기존 전신치료(중등도~중증 아토피피부염, 국소치료로 조절 불충분 또는 부적합 환자):
  - 사이클로스포린 사용 권고(A / 1a / 98%)와 혈압·검사실 모니터링 권고(A / 1a / 98%). 본문은 신독성·고혈압 등을 부작용으로 들고, 치료 전 간염·HIV·결핵 선별을 권한다.
  - 메토트렉세이트 선택적 사용 제안(B / 1b / 84%), 아자티오프린 선택적 사용 제안(B / 1b / 58%, TPMT 검사 필요 서술), 마이코페놀레이트 제한적 사용 제안(C / 4 / 62%).
  - 전신 스테로이드 장기 사용은 권고하지 않음(D / 5 / 96%). 알리트레티노인은 손 습진에 제한적 사용 제안(C / 4 / 70%)이며 기형 유발 가능성을 가장 중대한 부작용으로 서술.
- 표 1에서 확인된 나머지 권고(본문 해설 없음, 상세는 Part II·보충자료): 생물학적 제제·JAK 억제제 권고는 MED-0407과 같다. 기타 치료로 광선치료 선택적 고려(B / 2b / 92%), 경구 H1 항히스타민 선택적 추가(B / 2b / 94%), 임상적 세균감염 시 단기 항생제 권고(A / 1a / 98%), 두경부 피부염에 경구 항진균제 선택적 고려(B / 2b / 72%), 흡입 항원 감작 환자에 알레르겐 면역요법 선택적 고려(B / 1b / 66%), 프로바이오틱스·프리바이오틱스·달맞이꽃 오일·비타민 D는 제한적 사용(모두 C / 2b). 소아·청소년(단기 전신 스테로이드, 전신 면역억제제 선택적 사용, 생물학적 제제 권고), 노인(지속 가려움 평가, 생물학적 제제·저용량 JAK 억제제 선택, 칼시뉴린 억제제 고려), 임신·수유(국소 스테로이드 사용 고려, 경구 사이클로스포린은 제한적 사용) 항목이 있다.

## 적용 조건·한계
- 피부과 전문의용 합의 지침이다. 환자에게 약을 지시하는 문서가 아니며, 개별 환자의 연령, 동반 질환, 임신 여부, 검사 결과에 따라 의사가 판단한다.
- 권고등급 A~D와 근거수준 1a~5, 70% 동의율 기준은 이 지침 고유의 체계다. 동의율이 70%에 못 미치는 항목이 표에 포함되어 있어 해당 권고는 신뢰도를 과장하지 않는다.
- 기존 전신치료의 장기 효능·안전성 자료는 생물학적 제제·JAK 억제제보다 적다고 본문이 직접 밝히며, 저비용 대안이라는 점을 고려한다고 서술한다.
- 2025년 문서이며 문헌 검색은 2023-12-31까지다. 국소 스테로이드 강도 분류와 약제 허가·연령 기준은 국내 최신 정보와 대조가 필요하다.

## 미검증·사용 금지
- 보충자료 1(세정·목욕 상세)·2(국소 PDE-4 억제제·JAK 억제제·진양제 등), 소아·노인·임산부 항목의 본문 해설, 그림·알고리즘은 읽지 못했다(미확보). 표 2(국소 스테로이드 강도별 약제 목록)는 요약하지 않았다.
- 약제 용량(스테로이드 외용량, 전신 약제 용량), 연고 도포량(FTU)과 목욕 온도·시간 등 구체 수치는 의도적으로 요약하지 않았다. 임상시험 결과 수치와 참고문헌 목록은 확인하지 못했다(미확보).
- 시청자에게 특정 약제·강도·용량·횟수를 개인 지시처럼 말하지 않는다.

## 영상 활용 메모
- 쓸 수 있는 메시지(일반 시청자 설명): 아토피피부염 관리의 기본은 보습제 꾸준한 사용, 자극 회피, 교육이며, 염증 조절에는 국소 스테로이드와 칼시뉴린 억제제를 상황에 맞게 사용한다고 대한아토피피부염학회 지침이 설명한다. 호전된 후에도 재발이 잦은 부위는 의사 지시에 따라 주 2~3회 정도 선제 치료를 하는 방법이 있다고 소개할 수 있다. 국소치료로 조절이 어려우면 전신치료를 전문의와 상의한다.
- 쓰지 말 것: 스테로이드를 두려워해 끊으라는 표현이나 반대로 임의 연장 사용 권유, 특정 강도·부위·도포량의 개인 지시, 전신 스테로이드를 쉽게 쓸 수 있다는 암시(장기 사용은 비권고), 식이 제한이나 진드기 회피를 모든 환자에게 필요한 것처럼 말하기, 동의율이 낮은 보조요법(프로바이오틱스·비타민 D 등)을 효과가 입증된 것처럼 소개.
