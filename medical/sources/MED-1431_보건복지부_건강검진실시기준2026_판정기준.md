## 핵심 근거
- **판정 구분(별표 4):**
  - 정상A: 건강 양호
  - 정상B(경계): 이상은 없으나 자가관리·예방조치 필요
  - 일반 질환의심: 추적검사나 전문 의료기관 진단·치료가 필요
  - 고혈압·당뇨병·이상지질혈증 질환의심: 진료·검사가 필요
  - 유질환자: 고혈압·당뇨병·이상지질혈증·폐결핵·우울증·조기정신증·C형간염·만성폐쇄성폐질환으로 진단받고 약물 치료 중
  - 구강: 양호·주의·질환의심·치료필요
- **검사항목별 기준(별표 4의 별첨, 정상A / 정상B / 질환의심):**
  - 혈압(mmHg): 120 미만이고 80 미만 / 120~139 또는 80~89 / **140 이상 또는 90 이상**
  - BMI(kg/m²): 18.5~24.9 / 25~29.9 / 18.5 미만 또는 30 이상
  - 허리둘레: 남 90cm 미만·여 85cm 미만이면 정상, 남 90·여 85 이상이면 질환의심(비만)
  - 혈색소(g/dL): 남 13.0~16.5 / 12.0~12.9 / 12.0 미만, 여 12.0~15.5 / 10.0~11.9 / 10.0 미만
  - 공복혈당(mg/dL): 100 미만 / 100~125 / **126 이상**
  - 총콜레스테롤: 200 미만 / 200~239 / 240 이상
  - HDL: 60 이상 / 40~59 / 40 미만
  - 중성지방: 150 미만 / 150~199 / 200 이상
  - LDL: 130 미만 / 130~159 / 160 이상(당뇨병이 있으면 LDL 100 미만 목표, 의사 판단으로 수정 가능)
  - AST(U/L): 40 이하 / 41~50 / 51 이상
  - ALT(U/L): 35 이하 / 36~45 / 46 이상
  - γ-GTP(U/L): 남 11~63 / 64~77 / 78 이상, 여 8~35 / 36~45 / 46 이상
  - 요단백: 음성 / 약양성 / 양성(+1) 이상
  - 혈청 크레아티닌: 1.5mg/dL 이하 정상 / 1.5 초과 질환의심
  - e-GFR: 60 이상 정상 / 60 미만 질환의심
  - 흉부방사선: 정상 / 비활동성 폐결핵 / 그 밖
  - 골밀도(양방사선 등): T-score −1 이상 / −1~−2.5 초과 / −2.5 이하
  - 정량적 CT 골밀도(mg/㎤): 120 초과 / 80~120 / 80 미만
  - 노인신체기능 하지기능: 10초 이내 / 11~19초 / 20초 이상

## 적용 조건·한계
- '질환의심'은 확진이 아니다. 확진검사 안내와 본인부담 면제는 MED-1433.
- 별첨의 나머지 항목(평형성, 인지·정신건강 점수 기준, 구강 세부)은 정리하지 않았다.

## 미검증·사용 금지
- 검진 판정 수치를 질병 진단 기준처럼 말하지 않는다(예: 공복혈당 126 한 번으로 당뇨병 확진 아님).

## 영상 활용 메모
- '검진표에서 혈압 140/90, 공복혈당 126 넘으면 질환의심 → 다음 해 3월 31일까지 병·의원 확진검사 무료' 흐름 장면(MED-1433과 함께).
