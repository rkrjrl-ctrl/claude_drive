## 핵심 근거
- **전체 합계(3대 비급여 포함) 보험료 인상률(2026년 / 2025년 / 2024년)**
  - 손보: 메리츠 16.7 / 11.3 / 11.2%, 한화 21.7 / 14.3 / 2.1%, 롯데 101.5 / 19.2 / 0.0%, 흥국 9.1 / 12.4 / 14.5%, 삼성화재 21.1 / 16.8 / 0.0%, 현대해상 21.0 / 20.8 / 6.5%, KB 21.0 / 13.9 / 9.9%, DB 23.6 / 19.5 / 7.2%, 신한EZ 24.4 / 10.8 / 0%, 농협손보 17.6 / 20.3 / 0.0%.
  - 생보: 한화생명 15.7 / 17.9 / 0.0%, 삼성생명 19.7 / 10.2 / 0.0%, 흥국생명 17.9 / 15.8 / 0.0%, 교보생명 15.8 / 8.0 / 0.0%, 농협생명 0.4 / 0.1 / 0.0%, DB생명 13.2 / 9.1 / 0.0%, 동양생명 16.0 / 12.2 / 0.0%.
- **전체 합계 경과손해율(2025년 / 2024년 / 2023년)**: 현대해상 124.1 / 122.6 / 130.5%, 농협손보 124.3 / 122.3 / 125.3%, DB 109.8 / 108.1 / 112.1%, KB 104.0 / 102.1 / 108.6%, 메리츠 103.6 / 112.9 / 108.9%, 삼성화재 100.1 / 96.5 / 102.4%, 한화 97.0 / 96.6 / 91.5%, 동양생명 176.3 / 118.4 / 114.2%, 한화생명 112.1 / 123.5 / 113.2%, 삼성생명 87.6 / 89.0 / 90.9%.
- 담보별로 보면 상해 손해율이 질병보다 높은 회사가 많다(예: 메리츠 2025년 상해 117.2%, 질병 102.1%).

## 적용 조건·한계
- 회사별 공시값이다. 업계 평균 인상률은 화면에 없다.
- 롯데손보 2026년 인상률 101.5%(질병 121.5%)처럼 다른 회사와 크게 다른 값이 있다. 화면 표시 그대로이며 원인(전년 동결 반영 등)은 적혀 있지 않다.
- 인상률은 보험료수익 비중으로 가중한 평균이라 개인의 실제 갱신 인상률과 다르다(나이 증가분 등).

## 미검증·사용 금지
- 1~3세대 구분별 평균 인상률은 이 화면에 없다(요청한 '세대별 평균 인상률' 미확보). 2027년 인상률은 아직 공시되지 않았다(2026-10-18 기준 열은 2024~2026년).
- 탭 이름(표준화)과 주석(4세대 산정)이 맞지 않아, 이 숫자를 특정 세대 인상률로 단정하지 않는다.
