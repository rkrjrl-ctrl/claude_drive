# 영상용 숫자 카드표 (numbers/)

쇼츠 자막이나 도해에 바로 넣을 핵심 숫자를 한 줄에 하나씩 모은 표다. 숫자마다 근거 기록(`sources/MED-NNNN_*.md`)이 하나씩 붙어 있다.
2026-10-18 작성, 같은 날 2차 추가(Claude Code, 자료정리). 의료인·법률 전문가 검토는 하지 않았다.

| 파일 | 내용 |
|---|---|
| `numbers.csv` | 카드 304줄(1차 N-0001~N-0243, 2차 N-0244~N-0304). UTF-8, 엑셀에서 열 수 있다 |
| `verify_numbers.py` | 각 줄의 숫자가 출처 기록 본문에 그대로 있는지 대조하는 스크립트 |

## 열 설명

| 열 | 뜻 |
|---|---|
| 카드번호 | `N-0001`부터. 영상 대본·스토리보드에서 이 번호로 부른다 |
| 주제 | 묶음 이름(아래 '주제별 개수' 참고) |
| 숫자 | 출처 기록 '핵심 근거' 절에 적힌 글자 그대로. 표기를 바꾸지 않았다(예: `1,162,375`·`4만 3,664`·`약 1479만`) |
| 단위 | 숫자 열의 단위. `천 원`·`억 원`·`천 명`처럼 원문 단위를 따른다. 기간·대상이 숫자인 줄(예: `5년`, `간암`)은 `-` |
| 한 줄 문장 | 자막용 문장(40자 이하). 숫자 열의 값을 우리말로 읽기 쉽게 풀어 쓴 것뿐이며 반올림·환산을 하지 않았다(예: 5,508천 원 → '550만 8천 원') |
| 기준시점 | 진료분·심사분·발표일·시행일 등 숫자가 가리키는 때 |
| 출처기록 | 근거 기록 번호 |
| 출처기관 | `index.csv`의 `org` 값 그대로 |
| 재확인기한 | 출처 기록의 `recheck_by` 그대로. 이 날짜가 지났으면 원문을 다시 확인한 뒤 쓴다 |
| 주의 | 직접 계산 여부, 적용 범위, 함께 말해야 할 조건, 쓰면 안 되는 해석. 출처 기록의 '적용 조건·한계'와 '미검증·사용 금지'에서 옮겼다 |

## 쓰는 법

1. 대본에 숫자를 넣을 때 카드번호를 함께 적는다. 화면이나 설명란에는 출처기관을 적는다.
2. **주의 열을 꼭 읽는다.** 특히 아래 표시가 있는 줄:
   - '직접 계산' 또는 '직접 합산': 기관 발표값이 아니라 기록 작성 때 계산한 값이다(23줄). 화면에 '약'을 붙이거나 계산값임을 밝힌다.
   - 'tier B': 공공기관 화면·보도자료·학회 자료다. 숫자를 그대로 쓰되, 제도·급여 판단의 근거로 말하지 않는다.
   - '심사 기준': 심평원 심사년도 통계라 같은 질병의 연보(진료연도 기준) 값과 숫자가 다르다. 두 기준을 한 화면에 섞지 않는다.
3. 재확인기한이 지났거나 영상 공개일이 3개월 넘게 지나면 출처 기록을 다시 연다(README 체크리스트 3번).
4. 숫자를 영상에 썼으면 출처 기록의 `video_use`에 적는다(이 표에는 적지 않는다).

## 고른 기준

- `status: verified` 기록만 썼다. tier C 기록은 쓰지 않았다(대조 스크립트로 확인, 해당 0줄).
- BL-37 보강분(MED-1467~1831)을 먼저 골랐다: 분쟁·민원, 부지급률·의료자문, 유지율, 실손 실적·손해율·인상률, 보장률, 질병별 진료비, 비급여 가격, 투석, 상한제 환급, 재난적의료비. 1차에서는 개별 분쟁조정 결정서(사건별 금액)를 '핵심 숫자'가 아니라고 보고 넣지 않았다(2차에서 새 결정례 금액을 요청에 따라 추가).
- 그다음 제도 핵심 숫자를 넣었다: 산정특례(MED-0104·1046·1047), 본인부담상한액(MED-0030·1288), 본인부담률(MED-1406·1438·1447), 실손 표준약관 세대별 자기부담(MED-1451~1457), 도수치료 관리급여(MED-1391·1594), 암검진(MED-1234).
- 같은 숫자가 여러 기록에 있으면 원 발표 기록을 출처로 했다(예: 도수치료 가격은 복지부 보도자료 MED-1594, 40% 보상 규정은 표준약관 MED-1451).
- 같은 질병의 공단 연보(진료연도)와 심평원 통계(심사년도)가 둘 다 있으면 연보를 기본으로 하고, 심평원 2025년 심사분은 몇 줄만 '심사 기준'으로 따로 넣었다.
- 처음 고른 280줄에서 회사 하나의 값, 비슷한 보장률·진료비 줄 등 37줄을 빼 목표 범위(150~250줄)에 맞췄다.
- **2차 추가(N-0244~N-0304, 61줄)**:
  - 새 기록: 심평원 진료행위 통계(MED-1830 투석·1831 체외충격파) 8줄, 분조위 결정례(MED-1832~1850) 16줄, 법령 개정(MED-1851~1856) 10줄. 결정례는 2차 요청에 따라 지급·분쟁 금액을 카드로 넣었고, 결정서가 인용한 의학 수치(MED-1837 '약 1/3', 1838 '생존율 75%', 1842 '62.8%', 1846 '18개월·24개월·3%', 1848 '정확도 약 95%')는 기록이 쓰지 말라고 해 넣지 않았다. MED-1839·1840·1843·1845·1850·1853·1857은 카드로 쓸 만한 숫자가 없어 뺐다.
  - 질병 패키지 8종(전립선암·간암·혈액암·신장암·췌장암·당뇨병·만성콩팥병·파킨슨병)용 27줄: 5년 상대생존율(MED-1463, tier A), 국가암등록(MED-0116), 신규 산정특례 등록(MED-1545), 진료비·진료인원 보완(연보), 혈액암 보장률(MED-1553), 질병 안내 자료(MED-1041·1045·1051, tier B).
  - 질병 패키지용으로 쓰지 않은 것: 국가암정보센터 암종별 통계(MED-0112·0113·0115)는 기록이 '원 발표 대조 전 화면 수치 사용 금지'라고 해 넣지 않고 원 발표(MED-0116·1463)를 썼다. 암종별 요약병기 생존율(MED-1079·1092·1101·1104)은 기록의 미검증 항목이 '원 통계 대조'라 넣지 않았다. 혈액암 5년 생존율은 verified 기록에 없다. MED-1041의 '1인당 진료비 849만 원'은 출처 연도 미확인이라 뺐다.

## 결론이 엇갈리는 기록

- 실손 40% 보상(N-0243): 분조위 결정 MED-1818(공제가 낸 치료비의 40% 지급)과 MED-1701(지원금 공제 전 의료비 기준)은, 기록 스스로 이후 대법원의 '실제 부담분만 보상' 판결(MED-1622~1625)과 결론이 다를 수 있다고 적었다. 그래서 이 두 결정의 숫자는 카드로 만들지 않고 N-0243 주의 열에만 적었다.
- 같은 대상인데 기준이 달라 숫자가 다른 것: 말기콩팥병 유병자(청구자료 MED-1784 126,944명 / 등록자료 MED-1785 134,826명 / 심평원 혈액투석 행위 MED-1830 89,812명), 실손 가입 규모(피보험자 4천만 명 MED-1750 / 계약 3,622만 건 MED-1530). 주의 열에 서로를 적어 두었다.
- 암 산정특례 본인부담: 제도상 5%(N-0221)인데 연보 표로 계산한 법정 본인부담 비율은 8.4%(N-0180)다. 이유는 기록에 없어 적지 않았다.

## 작성 중 빼거나 고친 것

출처 기록 본문과 글자가 맞지 않아 그대로 넣지 않은 것:

| 처음 쓴 값 | 문제 | 처리 |
|---|---|---|
| MED-1543 `116조 2,375억` | 기록 제목에만 있는 표기이고 '핵심 근거'에는 `1,162,375`(억 원)로 적혀 있음 | 숫자 열을 `1,162,375`(억 원)로 바꿈(N-0061) |
| MED-1544 `2,294만` 명 | 제목 표기. 본문은 `22,937`천 명 | `22,937`(천 명)로 바꿈(N-0064) |
| MED-1729 `43,664` 명 | 본문은 `4만 3,664명` | `4만 3,664`로 바꿈(N-0164) |
| MED-1681 식도암 '13위', 방광암 '33위' | 기록에는 순위 구간 목록만 있고 개별 순위 숫자는 없음(목록 위치로 내가 센 값) | '11~20위 묶음', '31~40위 묶음'으로 고침 |
| MED-1528 '17개사' | 기록 제목에만 있고 본문에 없음 | 주의 열에서 뺌 |
| 자막 문장의 반올림 4개 | '551만 원'(5,508천 원), '2,294만 명'(22,937천 명), '약 1,509만 원'(15,087,669원), '약 280만 원'(2,801,270원) | 원값을 풀어 쓴 문장으로 고침 |
| 2차: MED-1830 진료금액 '1조 1,684억 8,572만 원' | 원문은 `1,168,485,720`천 원. 억 단위 환산은 내가 한 계산 | 문장과 주의 열을 원문 단위 그대로 고침(N-0247) |
| '작년·올해' 표현 | 시간이 지나면 틀린 말이 됨 | 연도를 직접 적음 |

기록 스스로 쓰지 말라고 적어 넣지 않은 숫자(예):

- MED-1729 언론 보도의 혈액투석 '10만 4,157명·3조 5,145억 원'(보도자료에 없는 수치).
- MED-1518 '부지급의 44%가 고지의무 위반' 같은 비율(직접 계산값, 기록이 화면 수치처럼 쓰지 말라고 함). 건수만 넣었다.
- MED-1527 '소비자가 소송하면 80% 진다' 식 해석, MED-1651 '자동차보험 부지급의 37%가 보험사기'.
- MED-1734 '암 환자는 1년에 평균 73만 원만 낸다', MED-1545 '암 첫해 치료비 1,500만 원'.
- MED-1785 '세계 3번째 발병률(100만 명당 360.2명)'(읽은 쪽에서 확인 못 함).
- MED-1530 '1인당 비급여 치료 사용액(추정)', MED-1750 '보험료 30~50% 인하'(시뮬레이션 추정치).
- MED-1688 선택형 할인·전환 할인은 2026년 11월 시행 예정이라 '시행 중'으로 쓰지 않도록 주의 열에 적었다.

## 출처 기록 수정 중 표시

2026-10-18 수집E 세션이 고치는 기록(MED-1244, 1060, 0114, 1081, 1473, 1474, 1828, 1513, 1690)을 출처로 쓴 카드는 1·2차 모두 없다. 그래서 주의 열에 '출처 기록 수정 중(2026-10-18)' 표시를 붙인 줄도 없다. 이 기록들로 카드를 새로 만들 때는 수정이 끝난 뒤 대조한다.

## 고칠 때

- 출처 기록이 갱신되면(`checked`·`recheck_by` 변경, 숫자 수정) 해당 카드의 숫자·재확인기한을 고치고 `verify_numbers.py`를 다시 돌린다.
- 새 카드는 맨 끝 번호 다음부터 붙인다. 지운 카드 번호는 다시 쓰지 않는다.
