## 열 설명

| 열 | 뜻 |
|---|---|
| 카드번호 | `N-0001`부터. 영상 대본·스토리보드에서 이 번호로 부른다 |
| 주제 | 묶음 이름(아래 '주제별 개수' 참고) |
| 숫자 | 출처 기록 '핵심 근거' 절에 적힌 글자 그대로. 표기를 바꾸지 않았다(예: `1,162,375`·`4만 3,664`·`약 1479만`) |
| 단위 | 숫자 열의 단위. `천 원`·`억 원`·`천 명`처럼 원문 단위를 따른다. 기간·대상이 숫자인 줄(예: `5년`, `간암`)은 `-` |
| 한 줄 문장 | 자막용 문장(40자 이하). 숫자 열의 값을 우리말로 읽기 쉽게 풀어 쓴 것뿐이며 반올림·환산을 하지 않았다(예: 5,508천 원 → '550만 8천 원') |
| 기준시점 | 진료분·심사분·발표일·시행일 등 숫자가 가리키는 때 |
| 출처기록 | 근거 기록 번호 |
| 출처기관 | `index.csv`의 `org` 값 그대로 |
| 재확인기한 | 출처 기록의 `recheck_by` 그대로. 이 날짜가 지났으면 원문을 다시 확인한 뒤 쓴다 |
| 주의 | 직접 계산 여부, 적용 범위, 함께 말해야 할 조건, 쓰면 안 되는 해석. 출처 기록의 '적용 조건·한계'와 '미검증·사용 금지'에서 옮겼다 |

## 쓰는 법

1. 대본에 숫자를 넣을 때 카드번호를 함께 적는다. 화면이나 설명란에는 출처기관을 적는다.
2. **주의 열을 꼭 읽는다.** 특히 아래 표시가 있는 줄:
   - '직접 계산' 또는 '직접 합산': 기관 발표값이 아니라 기록 작성 때 계산한 값이다(70줄). 화면에 '약'을 붙이거나 계산값임을 밝힌다.
   - 'tier B': 공공기관 화면·보도자료·학회 자료다. 숫자를 그대로 쓰되, 제도·급여 판단의 근거로 말하지 않는다.
   - '심사 기준': 심평원 심사년도 통계라 같은 질병의 연보(진료연도 기준) 값과 숫자가 다르다. 두 기준을 한 화면에 섞지 않는다.
3. 재확인기한이 지났거나 영상 공개일이 3개월 넘게 지나면 출처 기록을 다시 연다(README 체크리스트 3번).
4. 숫자를 영상에 썼으면 출처 기록의 `video_use`에 적는다(이 표에는 적지 않는다).

## 고른 기준

- `status: verified` 기록만 썼다. tier C 기록은 쓰지 않았다(대조 스크립트로 확인, 해당 0줄).

- 그다음 제도 핵심 숫자를 넣었다: 산정특례(MED-0104·1046·1047), 본인부담상한액(MED-0030·1288), 본인부담률(MED-1406·1438·1447), 실손 표준약관 세대별 자기부담(MED-1451~1457), 도수치료 관리급여(MED-1391·1594), 암검진(MED-1234).
- 같은 숫자가 여러 기록에 있으면 원 발표 기록을 출처로 했다(예: 도수치료 가격은 복지부 보도자료 MED-1594, 40% 보상 규정은 표준약관 MED-1451).
- 같은 질병의 공단 연보(진료연도)와 심평원 통계(심사년도)가 둘 다 있으면 연보를 기본으로 하고, 심평원 2025년 심사분은 몇 줄만 '심사 기준'으로 따로 넣었다.
