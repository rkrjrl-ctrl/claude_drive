# 원문 변경 재확인 2026-11 (A: 점검표 3~25번, 23건)

34라운드(2026-11-01) 숫자표 세션이 확인했다. 대상은 `점검_2026-11.md` '11월 1일 점검 결과'의 '저장소 기록이 인용한 원문이 바뀐 줄' 표에서 3~25번이다. 26~88번은 다른 세션 두 곳이 본다.

- **확인한 방법**
  - 법령: 국가법령정보센터 웹 화면을 내장 브라우저로 열어, 현행 시행일·공포번호와 해당 조문 본문을 기록과 대조했다. 법령 API 공용 키는 이 PC에서 'IP 등록 필요'로 막혀 있다.
  - 손해보험협회 공시: 소비자포털 화면에서 분기를 골라 조회했다.
  - 심평원 비급여: 내장 브라우저가 hira.or.kr을 열지 못해 agent-browser를 썼다. 페이지 안에서 기록 note에 적힌 조회 주소 `/npay/rb/selectPlcSclAmtList.do`를 같은 형식으로 불렀다.
  - 심평원 빅데이터: `olap3thDsInfoTab1.do`에 상병 코드와 심사년도 2021~2025를 넣어 받았다.
